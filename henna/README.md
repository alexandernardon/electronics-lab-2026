# Group `henna` — Electronics Design Laboratory

Code, testbenches and lab results are **shared** by the group.
Journals (`*/journals/<your-codename>.md`) and the semester synthesis
(`synthesis/<your-codename>.md`) are **individual**.

Members are listed in `MEMBERS.md`.

## Layout

```
ex01_car_park_1/   src/  tb/  journals/
ex02_car_park_2/      src/  tb/  journals/
lab01_fpga/           src/  tb/  constraints/  results/  journals/
lab02_fpga/           src/  tb/  constraints/  results/  journals/
synthesis/            one file per member
```

## Commit prefixes

| Prefix | Use when |
|--------|----------|
| `[IMPL]` | Adding functionality you believe is correct |
| `[FIX]` | Correcting something that did not work |
| `[DEBUG]` | Investigating unexpected behaviour — commit before you understand it |
| `[TEST]` | Adding or modifying a testbench |
| `[REFLECT]` | Restructuring because your understanding changed |
| `[RESULTS]` | Adding bench data, waveforms or photographs |
| `[DOCS]` | Updating a journal or synthesis |

Commit from your own GitHub account, and only inside your own group folder.
